# Roadmap

Each version is planned as a short list of items with acceptance criteria, built, checked by an independent reviewer,
and shipped at its own link, with the earlier versions left as they were.

| Version | Accepted when |
| --- | --- |
| v2: a personal leaderboard (shipped) | After a round that makes your top 10 you enter a name; the top 10 (name, score, length, date) shows and stays in your browser |
| v3: speed levels and obstacles | You pick a starting speed; every few foods the level rises, the snake speeds up and obstacles appear; food never lands on an obstacle |
| v4: power-ups, themes and replays | Power-ups appear and change the run for a while; you can pick a theme; a finished run can be shared as a link that replays it exactly |
